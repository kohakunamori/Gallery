# Archived Aliyun AIGC source

This directory is a source snapshot taken from the retired `aigc.nyaneko.cn`
deployment on 2026-10-15.

It contains application source only. Runtime media, the local photo cache,
dependency/vendor directories, build output, archives, PHPUnit caches, and
credential-bearing environment files were deliberately excluded. The active
Gallery application and its deployment files remain at the repository root.

This snapshot is archival material and should not be deployed without a fresh
security and dependency review.
